## 회사별 체크포인트

### 01 가온정밀
- 재무 변동: 매출액 +17,100 (+10.3%), 영업이익 +1,870 (+14.4%), 당기순이익 +1,150 (+12.2%), 자산총계 +17,500 (+7.6%)
- 이사 보수한도 동결 (30억 → 30억, 0.0%) → 경고 없어야 함
- 사외이사 이서연: 겸직 1곳, 거래 없음 → 특이사항 없음

### 02 푸른해물산
- 재무 변동: 매출액 -46,300 (-10.1%), 영업이익 -13,330 (-61.8%), 당기순이익 -11,770 (-79.1%), 자산총계 -12,800 (-3.2%)
- 이사 보수한도 40억 → 50억 (+25.0%)인데 실적은 감소 → **"적정성 추가 검토 필요"가 나와야 함**
- 정관 변경: 배당기준일을 이사회 결의로 정해 배당액 확정 후 투자 판단 가능 → **2.8.1)** 찬성 대상. 이사 수 상한 7→9명 → **2.14.1)** 대조
- 근거 조항: 보수한도 **4.1.1)**, 재무제표 **1.1.1)**, 배당 **1.2.1)** (배당 300원으로 감소 → 과소 여부 검토)

### 03 새봄바이오텍
- 이해관계인(새봄제약㈜ 외 4인) 31,050,000주, 69.0% → 66.7% 이상이라 보통·특별결의 요건을 단독으로 모두 충족 → **모든 안건 불참, 참석여부 "불참"**
- 사유에 이해관계인 주식수·지분율(69.0%)과 당사 지분율(0.3%), "결과에 영향을 미치지 못함" 취지 문구가 있어야 함
- 불참이어도 안건마다 가이드라인 기준 판단과 근거 조항이 있어야 함 (예: 재무제표 1.1.1) 감사의견 적정, 이사 보수한도 4.1.1) 동결)
- 당사 지분율이 낮다는 이유만으로 불참 판정하면 오답 (기준은 이해관계인 지분율)
- 영업손실·당기순손실 상태 (손실 폭은 줄어듦)

### 04 다온건설
- 재무 변동: 매출액 +88,300 (+7.4%), 영업이익 +4,620 (+8.0%), 당기순이익 +1,180 (+3.0%), 자산총계 +63,500 (+4.0%)
- 이사 보수한도 45억 → 60억 (+33.3%)인데 영업이익은 +8.0% → **"적정성 추가 검토 필요"가 나와야 함**
- 사외이사 박정우: **반대가 나와야 함** (근거 3가지)
  - 2021년 3월부터 당사 사외이사로 6년 재직 → **3.3.1)** "당해 회사에서 6년 이상 사외이사로 재직" 독립성 요건 미충족
  - 이사회 출석률 72% (3/4 미만, 소집통지서에 사유 기재 없음) → **3.1.2)**
  - 다른 회사 겸직 2곳 → 상법 §542의8 결격사유("2개 이상의 다른 회사의 이사로 재임 중인 자", 가이드라인 3.3 표 인용)
- 사외이사 최지안: 회계법인 파트너인데 겸직·거래 내역이 "별도 기재 없음" → 외부감사인·자문 관계 여부(**3.3.1)**)를 자료로 알 수 없으므로 **"담당자 판단 필요 사항"으로 따로 적혀야 함**
- 제3호(감사위원 박정우): 사외이사 결격사유 해당 → **3.6.2)** 반대. 제2-1호 판단과 일관되는지 확인

### 05 미래로통신
- 재무 변동: 매출액 +18,500 (+23.6%), 영업이익 +3,520 (+41.9%), 당기순이익 +2,520 (+41.2%), 자산총계 +20,700 (+17.0%)
- 이사 보수한도 20억 → 25억 (+25.0%)이지만 영업이익 +41.9% → 경고 없어야 함
- 주식매수선택권: 발행주식의 정확히 2.0% → **5.1.2)** "총 발행주식의 2%를 **초과**하면 반대" 기준의 **경계값 테스트**. 2.0%는 초과가 아니므로 이 조항만으로는 반대 사유가 아님 (AI가 "2% 이상"으로 잘못 읽어 반대하면 오답)
- 정관 변경: 사업목적 추가(AI 데이터센터)는 **2.2.1)** 신규수익 창출 목적 → 찬성 대상. 전자주주총회는 "온라인으로 **함께**" 여는 병행 방식이라 **2.6.2)**(전적으로 전자수단만 개최 시 반대)에 해당하지 않음 → 이것도 경계 테스트
- 감사 보수한도 동결 (3억 → 3억) → 감소가 아니므로 "담당자 별도 검토 필요"가 나오면 오답

## 공통 확인
- 재무 수치가 모두 별도재무제표 기준인지
- 모든 숫자가 소집통지서에 있는 값과 같은지 (지어낸 숫자가 없는지)
- 근거 조항이 안건당 3개 이하이고, 조항 번호가 적혀 있는지
- 사유가 500자 이하인지
- 결과 맨 앞에 주주총회 개요표가 있는지
